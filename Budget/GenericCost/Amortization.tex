\textbf{Amortization}
\vspace{-5pt}

The amortization cost corresponds to the proportion of hardware resource usage time relative to their total usable lifespan. Hence, this cost is formulated as:

\vspace{-10pt}
\small
\[
\text{Amortization (\texteuro) }= \frac{\text{Resource Price}}{\text{Total Depreciation Hours}} \times \text{Project Usage Hours}
\]

\normalsize

The usage hours equal the project execution time, since hardware resources are used throughout the project. Assuming a four-year depreciation period and the same annual working hours from PC (260 working days * 7.5 working hours/day), which is a total of 1950 hours, the following equation is applied for each hardware resource in Table \ref{table:amortization-cost-of-hardware-resources}: 

\small

\vspace{-5pt}
\[
\text{Amortization (\texteuro)} = \text{Resource price} \times 
\dfrac{1}{4 \text{ years}} \times 
\dfrac{1 \text{ year}}{1950 \text{ working hours}} \times 
\text{hours used}
\]
\normalsize
