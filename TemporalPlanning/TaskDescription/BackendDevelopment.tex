\subsubsection{Backend Development}

The following tasks are implemented exclusively in the application backend logic.

\textbf{BD1. RESTful API Backend Logic Implementation}

Configure the backend architecture defined in the DT3 task and build a RESTful API to manage backend responsibilities through frontend requests.

\textbf{BD2. Azure SQL Database Integration}

Integrate Azure SQL Database with Entity Framework Core migrations to manage users' relevant information (e.g., extracted expense and report information, employees' hierarchy) and configure the initial database according to the diagram designed in DT2 task. 

\textbf{BD3. Azure Blob Storage Integration}

Store original expense files using Azure Blob Storage.

\textbf{BD4. Microsoft Document Intelligence AI Model Integration}

Automate the expense data extraction through the Microsoft Document Intelligence AI model integration.

\textbf{BD5. Automated AI-driven Data Extraction Pipeline}

Integrate Event Grid, Service Bus, and Azure Function and implement a mechanized data extraction workflow that prevents bottlenecks during multiple simultaneous uploads:

\begin{enumerate}
    \item Save the uploaded receipt file in the Blob Storage and store the receipt information in the SQL Database.
    \item Detect the event using Azure Event Grid and route the expense file to the Service Bus queue. 
    \item Once the new expense is in the queue, trigger the Azure Function to process the receipt file using the integrated AI model. 
\end{enumerate}

\textbf{BD6. Azure SignalR Real-time Notification Service Integration}

Integrate SignalR to configure a SignalR Hub that sends real-time expense status updates, eliminating manual page refreshing whenever the AI processes a new receipt file.

\textbf{BD7. Microsoft Entra ID User Authentication Integration}

Handle employee authentication through the company email account by using Microsoft Entra ID integration.
