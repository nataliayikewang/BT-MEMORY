\subsubsection{Project Starting}

A solid project start requires a preliminary study and initial project definition. This aligns the project vision among all involved members and establishes a unified understanding of the project's scope and objectives. To achieve this, the subsequent tasks are defined:
 
\textbf{PS1. Context and Scope}

This task is divided into smaller sub-tasks:

\begin{itemize}[noitemsep]
    \item Analyze the current problem and identify all stakeholders.
    \item Define and propose a technical solution.
    \item Describe the project context and conduct a market study.
    \item Define the project scope in terms of objectives, requirements, obstacles, and risks.
    \item Select a pattern methodology to guide the entire project development.
    \item Select the monitoring and validation tools to be used in the project.
\end{itemize}

\textbf{PS2. Temporal Planning}

Identify all tasks and resources, design an initial Gantt diagram timeline, and define a risk management strategy.

\textbf{PS3. Budget and Sustainability}

Define a project budget and analyze the sustainability aspects of the proposed solution.

\textbf{PS4. Initial Documentation}

Consolidate the documentation from previous tasks into the definitive version of the initial documentation.
