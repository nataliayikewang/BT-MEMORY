\subsubsection{Development}

Essential tasks for the application development are specified in this task group.

\textbf{Dev0. Self-learning and study of unfamiliar technologies}

Study and learn new application technologies in advance.

\textbf{Dev1. Environment Configuration}

Configure a ready-to-use environment to begin application development: installing Visual Studio Code and essential extensions, creating a Git repository, and similar setup tasks.

\textbf{Dev2. Product Deployment}

Release the final product for end-user availability.

\textbf{Dev3. CI/CD Pipeline Implementation}

Implement Continuous Integration and Continuous pipeline to automate compilation, unit and integration testing, and building of every updated code version.

\textbf{Dev4. Logging and Monitoring}

Set up logging and monitoring tools to track application performance and review logs.

\textbf{Dev5. Git Repository Documentation}

Maintain clear repository documentation for a technical audience, including an application setup guide, API contracts documentation, and meaningful code comments.
