\subsubsection{Design}

This preliminary design phase establishes a clear application architecture to guide the subsequent development phase.

\textbf{DT1. Use Case Diagram}

Analyze all users’ interactions with the system and design a Use Case Diagram that illustrates all actors, use cases, and relationships between use cases.

\textbf{DT2. Conceptual Model Diagram}

Design the UML database diagram, clarifying all database entities, their attributes, and the relationships between them.

\textbf{DT3. Technology Stack Decision}

Select the technology to be used for each application layer and provide a clear technology selection documentation that serves as a guide for the application development phase.

\textbf{DT4. Logical and Physical Architecture Design}

Design the logical and physical application architecture. 

\newpage

The former describes how the implementation code is structured, including the purpose and role of each application layer. The latter explains how the application connects to external services and resources, both physical and virtual, and describes the function of each.

\textbf{DT5. UI mockups Design}

Deliver the mockup designs for each application page.

\textbf{DT6. Security Design}

Provide a security architecture design for user authentication, information submission and storage, and access control.
