\subsubsection{Personnel Cost}

To obtain realistic personnel cost estimates, the average hourly wage for each personnel member was calculated in advance using market salary data \cite{annual-spain-salary}. This calculation assumes 260 working days per year with an average of 7.5 working hours per day.

In Table  \ref{table:hourly-wage-of-personnel}, the hourly wage calculation for each member of personnel is specified. Note that the final number already includes the Social Security (SS) cost. Also note that personnel are categorized by roles rather than by the human resources (HR) identified in Section 5.2.1. Each resource is assigned to at least one role in the table. There are five different roles involved in this project:

\begin{itemize} [itemsep=-2pt]
    \item \textbf{Project Manager (PM)}: Responsible for planning and leading the entire project.
    \item \textbf{Junior Full-Stack Developer (SE)}: Responsible for the full coding implementation of the application
    \item \textbf{QA Tester (T)}: Responsible for verifying the applications' functionality.
    \item \textbf{Software Architect (SA)}: Responsible for designing the application's technical structure while considering the project requirements and scope.
    \item \textbf{Technical Writer (TW)}: Responsible for elaborating a clear and accurate project documentation.
\end{itemize}
