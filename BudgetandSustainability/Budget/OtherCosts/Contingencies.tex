\textbf{Contingencies}

No project strategy can eliminate the possibility of encountering obstacles. Therefore, a time buffer has been included to cover potential setbacks. However, simply adding extra time is insufficient, as it also entails additional resource consumption. Consequently, a portion of the project budget must be allocated for these potential scenarios. It has been decided to add a buffer of 15\% of the total general cost calculated so far (PC (\texteuro) + GC (\texteuro) = 13,370.03 + 1,600.63 = \texteuro14,970.65). The contingency cost amounts to \textbf{\texteuro2,245.60}.
