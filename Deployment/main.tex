\section{Deployment}

To enable end users to access the application, a deployment process is required. This application is deployed by publishing it on the Microsoft Azure cloud platform. Although Azure's Platform-as-a-Service (PaaS) offerings simplify this process, a manual deployment process is always required for the initial version.
