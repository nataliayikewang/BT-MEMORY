\subsection{Backend Deployment}

The .NET backend was deployed directly to the Azure App Service. The process consists of two steps:

\begin{enumerate} [leftmargin=0.75cm]
    \item \textbf{Publishing the Artifact}: The application is first published locally using Visual Studio's built-in “Publish” feature. This process compiles the C\texttt{\#} code, resolves all dependencies, and gathers all necessary files into an optimized zip file, which is later used as the deployment package. 

    \item \textbf{Deploying to Azure}: The obtained package was then deployed to the App Service using the “Zip Deploy” method via Azure CLI. Once the package is deployed, the App Service automatically unzips it and starts the application.

\end{enumerate}
