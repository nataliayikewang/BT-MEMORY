\subsubsection{\textbf{Use Case: Delete Individual Report}}

\textbf{Primary Actor:} User

\textbf{Trigger:} The user deletes a single report from the list.

\textbf{Preconditions:} The user is successfully authenticated and viewing the Reports page, and at least one report is displayed in the list.

\textbf{Postconditions:} The report is deleted.

\vspace{0.5cm}

\textbf{Main Success Scenario:}

\begin{enumerate} [leftmargin=0.75cm, noitemsep]
\item The user initiates the deletion of a single report in the list.
\item The system prompts the user to confirm the deletion.
\item The user confirms the deletion.
\item The system unassigns all expenses associated with the report, if applicable, and marks the report as deleted in the database.
\item The system restores the standard Reports page view with the updated list (without displaying the recently deleted report).
\end{enumerate}

\vspace{0.3cm}

\textbf{Extensions:}

\begin{itemize} [label={}, leftmargin=0.75cm, noitemsep]

\item \textbf{3a. Deletion Confirmation Rejected:}
\begin{itemize} [label={}, leftmargin=0.75cm, noitemsep]
    \item 3a1. The user declines or closes the confirmation dialog.
    \item 3a2. The system closes the confirmation dialog and restores the standard Reports page view.
\end{itemize}

\item \textbf{4a. Report Deletion Error:}
\begin{itemize} [label={}, leftmargin=0.75cm, noitemsep]
    \item 4a1. An error occurs during the report deletion due to a database connection error or an internal error.
    \item 4a2. The system notifies the user of the error and keeps the user on the report’s detailed information view.
\end{itemize}

\end{itemize}
