\subsubsection{\textbf{Use Case: Detach Multiple Expenses from Report}}

\textbf{Primary Actor:} User

\textbf{Trigger:} The user wants to remove new expenses from a report.

\textbf{Preconditions:} The user is authenticated, and the system displays a form containing the report metadata.

\textbf{Postconditions:} The selected expenses are excluded from the report.

\vspace{4.5cm}

\textbf{Main Success Scenario:}

\begin{enumerate} [leftmargin=0.75cm, noitemsep]
\item The user initiates the removal of expenses from the report.
\item The system enables bulk expense selection.
\item The user selects one or more expense records from the list.
\item The user requests to exclude the selected expenses from the current report.
\item The system prompts the user to confirm the action.
\item The user confirms the detachment.
\item The system removes the selected expenses from the current report and updates the report’s information accordingly, such as the total amount or expense count.
\item The system updates the detailed information view of the report to reflect the current changes.
\end{enumerate}

\vspace{0.3cm}

\textbf{Extensions:}

\begin{itemize} [label={}, leftmargin=0.75cm, noitemsep]

    \item \textbf{3a. No Expenses Attached:}
    \begin{itemize} [label={}, leftmargin=0.75cm, noitemsep]
        \item 3a1. No expenses are attached to the report; the system displays an empty list.
        \item 3a2. The user cannot select any expense to detach.
    \end{itemize}

    \item \textbf{6a. Detachment Confirmation Rejected:}
    \begin{itemize} [label={}, leftmargin=0.75cm, noitemsep]
        \item 6a1. The user declines or closes the confirmation dialog.
        \item 6a2. The system closes the confirmation dialog and preserves the current expense selection without detaching any expenses.
    \end{itemize}

    \item \textbf{7a. Expense Detachment Error:}
    \begin{itemize} [label={}, leftmargin=0.75cm, noitemsep]
        \item 7a1. An error occurs during the expense detachment due to a database connection error or an internal error.
        \item 7a2. The system notifies the user of the error and restores the detailed information view of the report.
    \end{itemize}

\end{itemize}
