\subsubsection{\textbf{Use Case: Delete Multiple Reports}}

\textbf{Primary Actor:} User

\textbf{Trigger:} The user activates the bulk report deletion mode.

\textbf{Preconditions:} The user is successfully authenticated and viewing the Reports page, and at least one report is displayed in the list.

\textbf{Postconditions:} The selected reports are deleted.

\vspace{0.5cm}

\textbf{Main Success Scenario:}

\begin{enumerate} [leftmargin=0.75cm, noitemsep]
\item The user activates bulk report deletion mode.
\item The user selects one or more reports from the list.
\item The user initiates the deletion of the selected reports.
\item The system prompts the user to confirm the bulk deletion.
\item The user confirms the deletion.
\item The system unassigns all expenses associated with the selected reports, if applicable, and marks the reports as deleted in the database.
\item The system restores the standard Reports page view with the updated list (without displaying the recently deleted reports).
\end{enumerate}

\vspace{0.3cm}

\textbf{Extensions:}

\begin{itemize} [label={}, leftmargin=0.75cm, noitemsep]

\item \textbf{1-3a. Cancel Deletion or Deactivate Mode:}
\begin{itemize} [label={}, leftmargin=0.75cm, noitemsep]
    \item 1-3a1. The user cancels the operation or deactivates bulk deletion mode.
    \item 1-3a2. The system clears all active selections, deactivates bulk deletion mode without deleting any records, and restores the standard Reports page view.
\end{itemize}

\item \textbf{5a. Deletion Confirmation Rejected:}
\begin{itemize} [label={}, leftmargin=0.75cm, noitemsep]
    \item 5a1. The user declines or closes the confirmation dialog.
    \item 5a2. The system closes the confirmation dialog and preserves the current selection without deleting any records.
\end{itemize}

\item \textbf{6a. Report Deletion Error:}
\begin{itemize} [label={}, leftmargin=0.75cm, noitemsep]
    \item 6a1. An error occurs during the bulk deletion due to a database connection error or an internal error.
    \item 6a2. The system notifies the user of the error and restores the standard Reports page view without deleting any report.
\end{itemize}

\end{itemize}
