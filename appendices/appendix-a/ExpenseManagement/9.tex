\subsubsection{\textbf{Use Case: Delete Current Expense}}

\textbf{Primary Actor:} User

\textbf{Trigger:} The user wants to delete the currently displayed expense.

\textbf{Preconditions:} The user is authenticated, and the system displays a form containing the expense metadata and the original receipt image or file.

\textbf{Postconditions:} The system deletes the currently displayed expense.

\vspace{0.5cm}

\textbf{Main Success Scenario:}

\begin{enumerate} [leftmargin=0.75cm, noitemsep]
\item The user initiates the deletion of the currently displayed expense.
\item The system prompts the user to confirm the deletion.
\item The user confirms the deletion.
\item The system deletes the currently displayed expense and returns the user to the Expenses page.
\end{enumerate}

\vspace{0.3cm}

\textbf{Extensions:}

\begin{itemize} [label={}, leftmargin=0.75cm, noitemsep]

    \item \textbf{3a. Deletion Confirmation Rejected:}
    \begin{itemize} [label={}, leftmargin=0.75cm, noitemsep]
        \item 3a1. The user declines or closes the confirmation dialog.
        \item 3a2. The system closes the confirmation dialog and preserves the current expense without deleting it.
    \end{itemize}

    \item \textbf{4a. Expense Deletion Error:}
    \begin{itemize} [label={}, leftmargin=0.75cm, noitemsep]
        \item 4a1. An error occurs during the expense deletion due to a database connection error or an internal error.
        \item 4a2. The system notifies the user of the error and keeps the user on the current expense information view.
    \end{itemize}

\end{itemize}
