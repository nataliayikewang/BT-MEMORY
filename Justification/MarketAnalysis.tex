\subsection{Market Analysis}
\label{sec:market-analysis}

The market already offers a bunch of available expense management applications. However, this analysis compares only a subset of the leading platforms \cite{best-expenses-tools}. Conducting a current market analysis helps identify industry gaps and standards and determine the most essential application functionalities.

To establish a baseline, the analyzed platforms are assumed to incorporate fundamental features of simplified expense management. This includes centralized expense data, digital expense management and reporting, streamlined information submissions, and secure login access through the company's employee account. 

To delve deeper into the main differences of available market offerings, consider Table \ref{table: comparative-analysis-leading-solutions}, which shows a comparative overview of these platforms. Green cells indicate features that the application offers, while red cells indicate the opposite. Each platform's pricing appears in the final row. These costs are only an estimation, since each model offers a customised plan.

The detailed analysis of Table \ref{table: comparative-analysis-leading-solutions} reveals two common industry features: AI-powered data extraction and OCR technology. The AI model serves as an automatic extraction tool for selecting relevant information from receipts, and OCR technology automates the conversion of a text-content image into a machine-readable text \cite{ocr-technology}.

Incorporating an AI model is essential for this project to streamline expense data extraction. The final product will integrate this tool, as outlined previously in Section \ref{sec:proposed-solution}. This approach replaces the previous tedious manual data entry and reduces human error. Nevertheless, OCR technology is intentionally omitted in this implementation, since the AI model already includes image data extraction.

Despite the strengths of these solutions, there are clear differences in their target markets and secondary features. For example, SAP Concur dominates the large enterprise sector, but it is often criticized for its non-intuitive user interface and high-cost plans.

In contrast, Zoho Expense and Expensify primarily target small businesses, offering more user-friendly interfaces, more affordable pricing, and additional features not included in SAP Concur. Additionally, Payhawk introduces a feature not offered by previous platforms: automated VAT receipt extraction \cite{expense-management-market} \cite{expense-management-evolution}.

The last column of Table \ref{table: comparative-analysis-leading-solutions} shows all the included features in the ongoing application. These are the AI model integration (as mentioned earlier), an intuitive user interface to minimize the learning curve and reporting time, plus a spending limit configuration to prevent misuse of the application.

However, as a small private company, FSP is not interested in all available market features. Customized approval processes lie beyond FSP's needs. Global reimbursements are unnecessary (expenses are added to monthly salaries). Virtual cards serve no purpose for the Barcelona team. Finally, automated VAT extraction lacks relevance.

Considering the last feature in Table \ref{table: comparative-analysis-leading-solutions}, FSP's demand an innovative feature not supported by existing platforms: real-time email notifications. This functionality alerts employees when an expense report has been rejected or approved, and notifies approvers when a report is submitted and pending review. This feature is essential at FSP, enabling employees to focus on core tasks while awaiting review results and freeing Finance from constantly checking pending reports.
