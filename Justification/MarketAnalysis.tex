\subsection{Market Analysis}
\label{sec:market-analysis}

The market already offers a bunch of available expense management applications. However, this analysis compares only a subset of the leading platforms \cite{best-expenses-tools}. Conducting a current market analysis helps identify industry gaps and standards and determine the most essential application functionalities.

To establish a baseline, the analyzed platforms are assumed to incorporate fundamental expense management features: centralized expense data and digital expense management, reporting, and submission. To delve deeper into the main differences of the available market offerings, refer to Table \ref{table: comparative-analysis-leading-solutions} for a comparative overview. Green cells indicate features that the application offers, while red cells indicate the opposite. 

As shown in Table \ref{table: comparative-analysis-leading-solutions}, two prominent industry features are AI-powered data extraction and OCR technology. The AI model serves as an automatic receipt extraction tool, and OCR technology converts a text-content image into a machine-readable text \cite{ocr-technology}.

Incorporating an AI model is essential for this project to streamline expense data extraction. This approach replaces the previous tedious manual data entry and reduces human error. Nevertheless, OCR technology is intentionally omitted in this implementation, since the AI model already includes image data extraction.

Despite the strengths of these solutions, there are clear differences in their target markets and secondary features. For example, SAP Concur dominates the large enterprise sector, but it is often criticized for its non-intuitive user interface and high-cost plans.

In contrast, Zoho Expense and Expensify primarily target small businesses, offering more user-friendly interfaces and additional features not included in SAP Concur. Additionally, Payhawk introduces a feature not offered by previous platforms: automated VAT receipt extraction \cite{expense-management-market} \cite{expense-management-evolution}.

The last column of Table \ref{table: comparative-analysis-leading-solutions} lists all the features included in the ongoing application. These are the AI model integration (as mentioned earlier), an intuitive user interface to minimize the learning curve and reporting time, plus a spending limit configuration to prevent misuse of the application.

However, as a small private company, FSP is not interested in all available market features. Customized approval processes lie beyond FSP's needs. Global reimbursements are unnecessary (expenses are added to monthly salaries). Virtual cards serve no purpose for the Barcelona team. Finally, automated VAT extraction lacks relevance.
\newpage
Considering the last feature in Table \ref{table: comparative-analysis-leading-solutions}, FSP's demand an innovative feature not supported by existing platforms: real-time email notifications. This functionality alerts employees when their submitted report has been rejected or approved, and notifies approvers when a new report is pending review.
