\subsection{Project Justification}
\label{sec:project-justification}

At this point, the development of this application is justified on several grounds and aligns the author's academic objectives with the FSP's business needs. 

First, there is an evident need for FSP to find a better expense management solution. Although numerous excellent options exist, none of them fit perfectly within FSP's specific context. All the applications cited in Section \ref{sec:market-analysis} provide excessive non-relevant features and lack a critical functionality required by FSP: the email notification service.

Second, as mentioned in Section \ref{sec:problems-to-solve}, FSP has 25 employees in the Barcelona team and 4 in the Finance department. Based on the real personnel wage at FSP, the annual cost for completing the current manual process is around €6750. The proposed application would \textbf{reduce} the required time by \textbf{75\%}, resulting in cost savings of \textbf{€5,062.5}. Based on the project budget defined in Section \ref{sec:budget}, the solution achieves a return on investment (ROI) within 3 years.

Third, this project marks the author's first independent application development. Consequently, it is a valuable opportunity to demonstrate key Software Engineering competencies in practice, including:

\begin{itemize} [leftmargin=0.75cm, noitemsep]
    
    \item Translating business needs into functional and non-functional technical requirements. 
    
    \item Developing a full-stack application based on a decoupled system architecture composed of 6 layers: infrastructure,  business logic, application, API, external parties, and interface. 

    \item Designing CI/CD pipelines in the code repository employing DevOps practices (more detailed in Section 3.2.2). 

\end{itemize}
