\subsection{Project Justification}

At this point, the development of this application can be justified on several grounds, perfectly aligning the author's academic objectives with the FSP's business needs. 

First, there is an evident need for FSP to find a better solution. Although numerous excellent options exist, none of them fit perfectly with FSP's specific context. All of the applications cited in Section \ref{sec:market-analysis} provide excessive features and lack a critical functionality required: the email notification service.

Second, as mentioned in Section \ref{sec:problems-to-solve}, FSP has 25 employees in the Barcelona team and 4 in the Finance department. Therefore, external applications demand annual costs ranging from €1,830.48 (Zoho Expense) to €7,621.20 (SAP Concur). By contrast, an internal application achieves return on investment within 2-8 years (based on the project budget defined in Section \ref{sec:total-cost}). Thus, adopting third-party solutions results in overspending for FSP.

Third, this project marks the author's first independent application development. Consequently, it is a valuable opportunity to demonstrate key Software Engineering competencies in practice, including:

\begin{itemize} [leftmargin=0.75cm, noitemsep]
    
    \item Translating business needs into functional and non-functional technical requirements. 
    
    \item Developing a full-stack application based on a decoupled system architecture composed of 6 layers: infrastructure,  business logic, application, API, external parties, and interface. 

    \item Designing CI/CD pipelines in the code repository employing DevOps practices (detailed in Section 3.2.2). 

    \item Employing external Azure cloud resources.

\end{itemize}
