\begin{abstract}
This bachelor's thesis addresses the inefficiencies of a manual expense management process in an IT consulting firm, which result in high operational overhead and an elevated error rate in expense reports. To solve this problem, the project designs and develops a full-stack web application that centralizes the workflow in a single digital platform and automates receipt data extraction.

The solution is implemented with .NET 8 for the backend layer, React with TypeScript for the frontend layer, and Microsoft Azure for cloud-hosted resources. The system architecture follows Clean Architecture and SOLID principles to enhance the application's maintainability, scalability, and integration with external services.

Additionally, the architecture separates synchronous and asynchronous operations. This design enables a fast, smooth user experience while computationally intensive AI-based receipt data extraction is processed in the background.

To ensure successful project delivery, requirement prioritization is guided by the MoSCoW methodology, allowing the project to remain within the planned time and budget while delivering the most valuable features. The resulting application successfully addresses the initial business problem and achieves an average efficiency improvement of 86.5\%.
\end{abstract}
